# 완료 작업과 검증 기록

작성일: 2026-10-14

## 선택한 방향

멀티모달 3D 시안 기반 맞춤 제작 견적·발주 플랫폼을 선택했다. 첫 제품군은 모듈형 진열대이며 선반 재료는 자작합판/강판, 프레임은 40 × 40 mm 강재로 가정한다. 실제 제조 도면과 ERPNext 연동은 다음 단계다.

## 구현 완료

- 한국어·영어 명시적 규격 해석, 단위 변환, 목표값/상대 변경, 지원하지 않는 표현 경고.
- 3D 진열대, 치수·재료 표시, 폭 1,400 mm 초과 시 중앙 지지 구조, GLB 내보내기.
- 서버의 치수·실제 선반 사이 간격 검증, BOM·자재비·공임·가산액·VAT 계산.
- 고객·메모·확인한 규격과 원본 요청 자료의 SQLite 영구 저장.
- 견적 버전·이력·감사 기록, 상태 전이, 충돌 처리, 승인한 데이터 잠금.
- 이미지 업로드, TripoSR 실행기, GLB 결과 조회. 음성 파일 업로드, Whisper 실행기, 전사 결과 조회.
- 이미지·음성 원본과 완료 모델 작업을 견적에 연결하고 다시 열 때 복원.
- 모델 준비/실패/진행 상태, 파일 크기 제한, 단일 GPU 작업 처리, 서버 재시작 중단 기록.
- CSV/JSON 내보내기, CSV 수식 주입 방어, 입력 출처·형식 검증, 공개되지 않는 로컬 실행 기본값.
- 모바일 레이아웃, 키보드 조작, 오류·대기·빈 화면.

## 리뷰로 수정한 사항

목표 치수를 증감량으로 해석하던 오류, 강재 프레임과 3D 재료 불일치, 선반 간격에서 프레임 두께가 빠진 오류를 수정했다. 늦은 모델 응답이 다른 견적에 반영되는 문제를 화면·작업 번호로 방지했다. 원본 자료를 영구 저장하고 변경 감지에 포함했으며, 승인/발주 이력 라벨과 모델 교체 시 GPU 자원 해제도 보완했다. 가격 문구는 데모 단가와 원가 가산율을 명확히 표시한다.

| 실제 TripoSR·Whisper CLI | GLB 생성·재조회, 음성 전사 성공 | [model-cli-smoke.json](verification/model-cli-smoke.json) |
| 일반 JPG 배경 제거·TripoSR | 실제 추론 성공, 9,766정점·19,532면 GLB | [jpeg-model-smoke.json](verification/jpeg-model-smoke.json) |

실제 TripoSR의 공식 의자 예제는 RTX 4070 Laptop에서 10.09초, 10,224정점·20,448면·410,068byte GLB를 생성했다. 같은 조건에서 PyTorch 최대 할당 메모리는 약 1.82GiB였으며 전체 GPU 점유량이나 다른 입력의 요구량을 의미하지 않는다. Whisper base는 공식 11초 영어 음성을 2.78초에 전사했다. HTTP 왕복·프로세스 로딩을 포함하면 각각 16.39초, 7.25초였으며 지연은 입력과 환경에 따라 달라진다.

브라우저 지연 오디오 검사는 제어한 응답 fixture다. 실제 모델 통합 검사는 별도 Python 추론기를 실행한다. 공식 의자와 영어 음성은 연결 검증이며 한국어 정확도·실제 진열대 재구성 품질·제조 안전성을 입증하지 않는다. 모바일 가로 넘침은 스모크에서 발견해 수정 후 재검증했다.

투명 PNG와 달리 배경 제거가 필요한 일반 JPG 경로도 별도로 실행했다. U2Net 배경 제거와 TripoSR 추론을 거쳐 36.64초에 391,744byte GLB를 생성했고 실행기는 종료 코드 0을 반환했다. 공식 예제를 변환한 입력 한 개의 결과다.
