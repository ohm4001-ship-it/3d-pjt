# Formworks 설계 결정

작성일: 2026-10-14 · 선택한 방향: 1번 맞춤 제작 3D 견적·발주 플랫폼

## 목적과 사용자

모듈형 진열대를 제작하는 업체의 영업·설계 담당자가 고객의 텍스트, 참고 사진, 음성 요청을 치수 확인, 3D 검토, 자재 목록, 견적, 승인과 발주 기록으로 연결한다. 취업 포트폴리오에서 AI 연동뿐 아니라 서버 계산, 데이터 관계, 변경 이력과 업무 상태 전이를 설명할 수 있도록 한다.

## 범위

- 제품군은 모듈형 직사각 진열대 한 종류, 재료는 자작나무와 강재 두 종류다.
- 사진으로 생성하는 외형 시안은 참고용이다. 제조 치수나 가격 계산의 근거로 사용하지 않는다.
- 치수 확인 후 규칙 기반 구조 모델과 자재 목록을 생성한다. 자유 생성 메시에서 자재량을 추정하지 않는다.
- 견적은 정수 원화로 서버에서 계산하고 SQLite에 저장한다. 견적 작성, 전달, 승인, 발주 전이는 서버가 검증한다.
- 승인 후 사양을 잠근다. 수정 이력과 승인한 버전을 보존하며 오래된 화면의 저장은 충돌로 처리한다.
- 실제 ERPNext, 결제, 회계, 재고 차감과 공장 생산 지시는 후속 작업이다. 현재 발주는 로컬 업무 기록이다.

## 입력과 3D

텍스트와 음성 전사 결과에서 치수·선반 수·재료·수량을 추출하고 사용자가 확인한다. 초기 한국어 규칙 파서는 지원 범위를 공개한다. 이미지 3D 생성은 TripoSR 실제 실행기로 연결하고, 환경이 준비되지 않거나 실행이 실패하면 해당 상태를 보여준다. 모델이 준비되지 않았을 때 생성 성공을 흉내 내지 않는다.

## 배포와 검증

Node.js 24, Vite, Three.js, SQLite로 로컬 웹 앱을 구성한다. Python 모델 실행기는 선택적 설치로 분리한다. 도메인 테스트, API 스모크, 실제 브라우저 시나리오를 구분하고 외부 모델의 실제 실행 결과를 별도로 기록한다. Git 원격 업로드, PR와 머지는 사용자 요청으로 보류한다.

## 성공 조건

1. 입력한 치수가 화면의 3D 구조와 자재·견적에 일관되게 반영된다.
2. 미확인 치수, 잘못된 값, 오래된 버전, 허용되지 않은 상태 전이는 서버가 거절한다.
3. 저장한 견적과 이력이 서버 재시작 후 유지된다.
4. CSV 및 3D 파일을 내보낼 수 있다.
5. 이미지/음성 모델의 준비·실행·실패 상태를 정확하게 표시한다.

## 첫 검증 과제

진열대 사진 5장과 요청 10개로 기능을 확인한다. 치수 추출 정확도, 모델 생성 성공률과 지연, 기준 자재 목록과의 일치 여부를 측정한다. 아직 검증되지 않은 제조 안전성이나 비용 절감 효과는 주장하지 않는다.
