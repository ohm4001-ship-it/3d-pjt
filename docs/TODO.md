## 1. 제품 검증과 제조 기준

- [ ] 제작 담당자 3명에게 실제 견적 변경 사례를 받아 작성 시간·누락 항목·재작업 횟수를 비교한다.
- [ ] 실제 진열대 사진 5장, 한국어 텍스트·음성 10개 이상의 평가 세트를 작성한다. 정답 치수·단위·부품 수를 별도 확정한다.
- [ ] 제조 전문가와 표준 프레임, 접합, 선반 지지, 하중, 처짐, 전도, 공차 기준을 확정한다.
- [ ] 제조 기준을 반영한 CadQuery 템플릿과 STEP/도면 출력으로 확장한다. 현재 GLB를 제조 도면으로 소개하지 않는다.
- [ ] BOM·가격 계산 기준 답안을 사람이 작성하고 자동 계산과 비교한다.

- [ ] ERPNext의 품목·BOM·견적 중 한 흐름을 API로 연동하고 실패/재시도/정합성을 검증한다.
- [ ] 로그인, 회사·고객별 데이터 격리, 담당자/승인자 권한, 실제 승인 증거를 추가한다.
