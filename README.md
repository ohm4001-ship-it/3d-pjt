# Formworks · 폼웍스

텍스트·참고 사진·음성 요청을 모듈형 진열대의 3D 검토, 자재 목록, 견적, 승인·발주 기록으로 연결하는 **로컬 포트폴리오 MVP**입니다.

## 실행

Node.js 24 이상이 필요합니다. 프로젝트 폴더에서:

```powershell
npm ci
npm run build
npm start
```

화면: http://127.0.0.1:4310

개발 중에는 `npm run dev`로 서버와 개발 화면을 함께 시작합니다. 개발 화면은 http://127.0.0.1:4325 입니다. 서버는 기본적으로 이 PC에서만 접속할 수 있습니다. 로그인·회사별 권한이 없으므로 인터넷/LAN에 공개하지 마세요.

## 사용할 수 있는 기능

- 한국어·영어의 명시적 치수, 재료, 선반 수, 제작 수량 해석. 목표값과 상대 변경 구분.
- 실제 WebGL 3D 구조, 치수 표시, 회전·확대, GLB 다운로드.
- 확인한 규격을 바탕으로 서버에서 BOM, 원가, 견적 가산액, 부가세 계산.
- 고객·메모·입력 원문·참고 이미지·완료 모델 작업·음성 전사의 견적 버전 연결.
- SQLite 영구 저장, 변경 이력, 오래된 버전 저장 거절, 승인 후 사양·금액·원본 잠금.
- 작성 → 고객 검토 → 승인 기록 → 발주 기록. 수정하면 다시 작성 단계로 전환.
- 견적 CSV/JSON 다운로드. CSV는 계산 가정과 제작 검토 필요 문구를 포함.
- TripoSR 실제 이미지→GLB 실행과 Whisper 음성 파일→텍스트 실행. 준비되지 않은 환경에서는 사용 불가 상태를 표시.
- 브라우저 음성 인식은 지원 브라우저와 마이크 권한이 필요하며, 브라우저 제공 서비스가 사용될 수 있습니다. 로컬 Whisper 파일 인식과는 별도입니다.

## 첫 시연

“폭 120cm, 깊이 45cm, 높이 150cm, 선반 3개, 자작나무로 만들어 주세요”를 입력해 반영합니다. 고객명과 확인 체크를 넣어 견적을 저장하고, “선반 한 개 추가”를 반영해 수정본을 저장합니다. 고객 검토와 승인 기록으로 진행하면 규격이 잠깁니다.

초기 화면의 규격은 1,200 × 450 × 1,500 mm, 선반 3개, 수량 1대입니다. 현재 **데모 단가** 기준 합계는 634,865원입니다. 원가 25% 가산은 매출 대비 이익률 25%를 의미하지 않습니다.

## 모델 환경

[모델 설치 안내](docs/MODEL_SETUP.md)를 참고합니다. Python 실행 환경과 가중치는 프로젝트 안에 저장하고 Git에서 제외합니다. 모델을 설치한 뒤:

```powershell
npm run models:check
npm start
```

모델 준비 상태는 서버 시작 때 읽습니다. 설치·검사가 끝난 뒤 서버를 다시 시작해야 이미지·음성 파일 처리 버튼이 활성화됩니다. 이미지와 음성 작업은 한 번에 하나씩 처리합니다. PNG/JPEG 또는 WAV/MP3/M4A 파일은 최대 8MB, 음성은 최대 120초입니다.

## 검증

```powershell
npm test
npm run build
npm run smoke
npm run smoke:browser
npm run smoke:models
```

브라우저가 없으면 `npx playwright install chromium`으로 설치하거나 `FORMWORKS_BROWSER`에 Chromium 실행 파일 경로를 지정합니다. 브라우저 스모크는 격리한 임시 데이터베이스를 사용합니다. 오디오의 늦은 응답 검사는 응답 fixture이며, 실제 모델 추론 검증과 분리합니다.

실제 GPU 추론 검사는 `model-service/smoke.py`와 모델 API 검증 보고서를 참고합니다. 검증 결과와 화면은 [docs/verification](docs/verification)에 있습니다.

## 데이터와 실제 업무의 경계

`data/`에 SQLite와 입력 파일·모델 결과가 저장됩니다. 이 폴더와 모델 가중치는 Git에 올리지 않습니다. 삭제·보존 정책과 자동 백업은 아직 구현하지 않았습니다.

이미지 생성 메시에는 실측 크기, 공차, 하중 검증이 없습니다. 규격 기반 GLB도 가공용 CAD/STEP 도면이 아닌 구조 시안입니다. 자재·보강·접합 규칙과 단가는 데모 가정이며 실제 제작 전 검토가 필요합니다. 고객 승인·발주는 담당자의 로컬 기록이며 외부 고객 서명, 공급사 주문, 실제 ERPNext 연동은 포함하지 않습니다.
